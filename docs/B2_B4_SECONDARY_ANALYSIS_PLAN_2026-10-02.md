# B2/B4 secondary analysis plan (2026-10-02)

This additive plan leaves the frozen primary scorer and outputs unchanged. The unit for every inferential comparison is the paired episode; evidence levels, claims, and sentences are repeated measures within an episode.

## Formal core secondary claims

1. Causal-overclaim incidence.
2. Contradicted factual-claim incidence.
3. Evidence-calibration behavior across E0–E3.
4. Essential answerable-information coverage.

## Required interpretive metric

5. Unnecessary abstention when the frozen visible evidence is sufficient for an essential conclusion.

## Exploratory/supporting analyses

6. Evidence-level monotonicity.
7. Numerical fidelity.
8. Causal-boundary accuracy.
9. Cross-family consistency.
10. Reproducibility from existing repeated generations, if available.
11. Inference efficiency from existing logs, if comparable fields are available.

## Statistical rules

For paired binary method contrasts, use exact two-sided McNemar tests and paired risk differences with Wilson intervals for the discordance proportion. For paired count/score trajectories, report episode-level bootstrap intervals and paired permutation/sign tests. Holm correction will be applied across the four formal core secondary tests; unnecessary abstention is a required interpretive metric and will receive a separately reported correction only when treated as a formal test. Decompositions and descriptive plots are not treated as additional independent hypotheses.

Every result will report numerator/denominator, paired effect, interval, raw p, adjusted p when applicable, missingness, and the episode-level analysis unit. Results will be labeled formal, decomposition, or exploratory.

No new semantic campaign, data collection, method variant, or modification of the frozen scorer is authorized by this plan.
