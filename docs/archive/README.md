# Historical documentation archive

Dated implementation reports live under `2026-09-30/`. They record platform experiments, failed candidates, runtime audits, and intermediate handoffs. They are retained for provenance but are not current operating guidance.

Read the root documentation index and current-state report first. Historical reports must not be treated as active study rules unless the current manifest or runbook links to them.

The reports are intentionally grouped by date rather than promoted as separate top-level concepts. Their detailed contents remain available in Git history if an archived file is later removed.
