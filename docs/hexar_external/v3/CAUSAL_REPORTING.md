# Prospective supplemental causal reporting

Defined before any reserved packet, method answer or comparative score exists. This is a descriptive secondary reporting repair identified by the independent deliverable audit. The sole primary endpoint, materiality, weights, references, support task, methods and masks remain unchanged. Earlier version results are not rescored. No new endpoint is selected for inference and no alpha is allocated.

The existing `unsupported_material_rate` includes noncausal asserted facts. The existing `unsupported_physical_cause_rate` uses a coarse developer extraction level, omits software/task causal links, and includes UNINTERPRETABLE in its non-supported flag. Final text must name those scopes honestly. Neither can be represented as a complete all-causal rate.

For the final v3 reserved report only, independently code a separate method-blind causal-role sidecar against the frozen atom inventory. Do not alter inventory statements, spans, abstraction indices or support labels. A positive causal/mechanism proposition asserts an explanatory, enabling, inhibiting or contributing relation, including software/task consequences, physical causes, conditionals and modal possibilities. Observation, temporal sequence, symptoms, requests, status, and explicit denial that a cause is established are not positive causal relations. A statement saying a recorded signal itself caused behavior remains a causal assertion; source attribution does not remove the relation. Preserve modality, polarity and scope. Ambiguous relations remain `null`, never favorable negatives.

The role coder may see only opaque IDs, unchanged answer text/spans and atomic statements; no keys, evidence/reference packets, production ontology or support outputs. A separate parent review uses the same blind projection, retaining any unresolved classification as unknown. This is developer extraction, not qualified or human-validated causal-role measurement. Qualified A/B/C **support** labels continue through the unchanged qualified interface. Role coding does not change those judgments or give methods additional facts.

For each answer, count a causal failure if at least one positively identified causal proposition is CONTRADICTED_BY_VISIBLE_EVIDENCE, INSUFFICIENT_VISIBLE_EVIDENCE or PHYSICALLY_TRUE_BUT_UNSUPPORTED. A known failure remains positive despite other missing fields. Otherwise an UNINTERPRETABLE causal support judgment, ambiguous causal role with nonsupported/unknown support, or technical/missing assessment leaves the answer's causal-failure status unknown. Noncausal uninterpretable statements do not establish a causal failure. Supported propositions with ambiguous role cannot establish unsupported causality. Fixed-denominator lower/upper rates count unknowns as zero/one respectively across all 324 jobs, grouped by the same twelve physical recordings; no extra independent N or causal significance test is introduced.

Report known failures, unknown answers and full-denominator bounds separately for all three methods. This descriptive categorization has role/extraction uncertainty and cannot establish human validity, physical truth or unique cause discovery. Preserve it even if it supplies no benefit or reveals baseline ties. Its result cannot replace the primary endpoint or motivate changing methods after reserved inspection.
