Qualify the prospective raw/native core on all six already exposed v17 development episodes, without acquiring or replaying a robot episode and without generating explanations or judge labels. Declare exactly six native reader calls, one per episode, with no retries/replacements and a fixed 180-second transport bound. Preserve every raw transport and failure. A separate host projection consumes the returned streams and original controller snapshots, preserving every query, evidence mask, reference and coverage rule. Acceptance requires all six reader transports close successfully; every returned event/motion stream equals its existing development extraction; every native result equals the retained original closed native review; all nine packet/reference projections per episode and their integrity review reproduce the original qualified interface exactly (normalizing only repository-relative bag paths). Also reverify original raw/source/image/intent/capture pins and confirm that original artifacts are unchanged. Missing or changed outcomes fail the complete-screen criterion; no criterion is tuned afterward.

This qualifies phase-aware, read-only extraction/projection at development scope, not a production acquisition authorization, new independent N, evaluator accuracy or a semantic endpoint.
