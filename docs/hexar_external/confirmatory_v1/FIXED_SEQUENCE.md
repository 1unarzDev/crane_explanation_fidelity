## Strong error-control argument

Let j be the first true null in the fixed order. Every false rejection requires reaching and rejecting H_j. Therefore

`P(any false rejection) ≤ P(the fixed valid H_j test rejects) ≤ .01`.

If H1 is true, any false claim requires a false H1 rejection. If H1 is false and H2 true, a false claim requires a false H2 rejection; imposing the H1 gate only restricts that event. If both nulls are false there is no false null rejection. This establishes strong familywise error control under every truth configuration. Cross-study independence is unnecessary. Each marginal test must itself control type-I error for its frozen null and population; the sequence does not repair an invalid paired test, outcome-adaptive endpoint, invalid heterogeneity assumption or optional stopping. No claim is made that H2 has conditional size .01 among only gate-passing worlds.

Across the program, the union bound remains `.02 + .01 + .02 = .05`, conditional on each family's valid procedures. Replication is untouched. H2's .01 threshold is not a second .01 charge and no alpha is refunded if H1 fails.

This matches the FDA's final October 2022 [Multiple Endpoints in Clinical Trials guidance](https://www.fda.gov/media/162416/download), section IV.D.5, “The Fixed-Sequence Method”: endpoints are tested in a predefined order at the same alpha, and testing stops at the first failure. The guidance was retrieved directly on 2026-09-30; its role is corroboration of the proof, not clinical authority over this robotics experiment.
