# Prospective parameter-event technical-validity amendment

**Development-only acquisition predicate amendment, before confirmation.** V14 used six new independent episodes at domain 70 in offline containers. All six execution exit codes were zero. The preserved v2 controller-boundary audit rejected the manual-priority episode because `/parameter_events` had zero recorded messages. Its raw bag audit passes, its applied seed matches the plan, and its actual boundary snapshot files are present. The failed v2 batch and first domain review remain immutable; they are not relabeled successful.

ROS parameter events occur on parameter declarations/changes. Requiring at least two observed events is not a general test of recorder integrity or continuous parameter stability. A fully recorded interval with no such changes can contain none. Presence also cannot prove that every event was delivered. The current scientific evidence interface provides typed parameter/graph snapshots at explicit action-bracketing boundaries and licenses statements at those boundaries only. It deliberately does not license continuous stability, complete command delivery or absence of intervening changes. Parameter-event records are not used to derive any required answer unit.

Adopt a separately versioned v3 development audit in which `/parameter_events` is an optional infrastructure channel. Record its actual count and keep absence unknown. Preserve strict requirements for readable bags, necessary sensor/task evidence, applied seed, actual action-window boundaries, valid start/end controller snapshots, query/mask construction and visible-evidence closure. Do not fill missing events or infer an unchanged configuration from their absence. The amendment applies to every family without considering navigation success, method answers or judge labels. It does not waive a required observation because a particular method failed.

The final acquisition predicate must incorporate this optional-channel disposition prospectively before any confirmation acquisition. A fresh episode is not created by this audit amendment: all six V14 bags remain permanently development-only. The scope review still does not establish the complete sampling population, family interventions, technical-invalidity rates or a confirmatory freeze. Subsequent records must distinguish missing optional parameter events from corrupted or missing required acquisition channels.
