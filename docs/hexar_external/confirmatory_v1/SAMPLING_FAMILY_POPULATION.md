# Prospective simulated population and family definitions

**Unbound candidate population; final acquisition qualification/N remain unfinished.** The benchmark is an adapted simulated HEXAR external-validation benchmark, not a held-out portion of the original HEXAR experiment. Every original recording and every designated development episode remains excluded. The experimental unit is one independently generated simulated TIAGo navigation episode in a fresh offline Gazebo/Nav2 container.

The current acquisition domain is the pinned first-party home map/world, no-arm TIAGo and differential-drive navigation. `sampling_frame_enumeration_v1.json` enumerates all 6,597 permitted start cell centres in the actual image assets. Every start has an eligible goal: minimum 976 and maximum 2,696. Map resolution is 0.05 m. The rectangular candidate region is x∈[−6,1.2], y∈[−0.5,2.0], with a conservative square clearance of 0.6 m in the released occupancy map. Start/goal distances are 3–5.5 m. This is map-based clearance, not independent proof of every world's geometric detail. The corrected first-party saved world layout and applied reset still require their separate runtime checks.

`sampling_frame_enumeration_v2.json` independently reproduces the original counts/map hashes using the versioned `enumerate_sampling_frame.py` in the actual pinned image, offline, with the verified captured sampler source bank. Five compatibility seeds also agree with the captured sampler's candidate counts and membership. This adds a reproducible report without changing the sampler, drawing robot episodes, or rewriting the original enumeration. Map enumeration alone is not final acquisition qualification.

For an episode, uniformly select a permitted start, then uniformly select a goal in its eligible distance set. Draw start and goal headings uniformly from [−π,π]. Seeds and derivation namespaces must be prospectively bound, unique against development schedules, and checked for collisions before acquisition. A shared immutable map/code/image is part of the target domain; processes, AMCL/controller state, caches, world mutations and message histories must not survive between episodes. Repeating a sampled location by chance is permitted; replaying, cloning or editing a recording is not an independent episode.

Retain all six known family names with equal fixed quotas. The operational definitions are:

| Family | Prospective simulated condition |
|---|---|
| `success` | Nominal navigation in the unmodified static environment with neither supervisor lock asserted. The historical family name is retained; a navigation failure is still valid. |
| `obstacle` | Spawn the specified static collision box at the requested goal and measure its applied pose before goal acceptance. No planner failure or diagnostic outcome is required. |
| `dynamic_env` | Spawn a kinematically moved collision box at the route midpoint, with independently derived sine-trajectory phase and native simulated time. Deliver/measure the pre-goal setup and continue the trajectory during navigation; do not require a particular Nav2 response. |
| `localization` | Apply/read back the five specified AMCL sensor-model parameters before the goal. Record actual AMCL estimates/logs, without inserting synthetic high-uncertainty diagnostics. The separately timed initial-pose perturbation is reported, not a validity requirement conditional on action duration. |
| `manual_joystick` | Assert the simulated supervisor manual-priority Bool and zero joystick command with observed actual twist_mux consumers. This is not a human-operated joystick experiment. |
| `charging` | Assert the simulated supervisor charging-interlock Bool with an observed actual twist_mux consumer. This is not evidence of physical battery charging. |

The [measured reset/family-delivery qualification](RESET_FAMILY_DELIVERY_QUALIFICATION.md) defines the applied-condition checks. Raw action results, timeouts, early termination, command absence and observed covariance are retained as outcomes. Method/judge inputs receive only the prospectively masked legitimate evidence interface, never seeds, planned family, intervention truth, hidden geometry or expected outcomes. All families use the same three neutral navigation queries and coverage requirements. Historical manipulation-containing question lists remain archived separately; no manipulation or independently verified room location is claimed in this no-arm domain.

The target is the average measured endpoint risk over the six equally weighted technically valid family processes. Ordered within-family reserves select the first required number passing frozen setup/recording predicates before semantic generation. This conditions the population on technical validity; all attempted invalid runs and their reasons must also be reported. The final reserve budget, formal predicates and acquisition adapter are not yet frozen. Exhaustion does not authorize N enlargement or outcome-driven replacement. Unequal-weight power rows remain sensitivity only and do not select a more favorable population.
