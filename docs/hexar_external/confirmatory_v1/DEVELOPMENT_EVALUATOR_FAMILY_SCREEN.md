# Provider-backed authored family screen

`development_evaluator_family_screen.py --stage pipeline` first exclusively declares six development-only technical preflight calls. A durable journal claim precedes every dispatch; exact stdout/stderr/final-file bytes and hashes are retained. The preflight validates schema acceptance, no observed tools/errors and latency only. Its labels cannot substitute for bank scoring.

Only six valid preflight returns permit a **new exclusive declaration** of all 122 A/B bank-scoring calls, with the same runtime settings, fixed prompt, unchanged 61-fixture bank and exact support/coverage agreement requirement. Each process runs in a separate empty temporary read-only workspace. Fixture identity, family, mask, expected labels and rationale are excluded from model input; required-unit definitions remain visible. Expected labels are joined after all scoring calls close. Any timeout, invalid return, observed tool/error event or disagreement fails the full screen. No old calls are retried and no stopping for favorable scores is permitted.

Raw final bytes are retained before closure, including an empty artifact if the final file is absent. Strict local validation rejects unknown fields, incorrect scalar types, illegal unit IDs and duplicate units, while avoiding the provider-unsupported `uniqueItems` keyword. A surviving claim after a crash is never reissued. Executing an already declared stage fails exclusive creation, preserving the original run.
