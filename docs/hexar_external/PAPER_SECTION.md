# External validation section — development-safe draft

**Status: supporting implementation evidence only; no external improvement claim is currently supported.** The table below recalculates historical human-annotated results. The fresh evidence-extension batch has no qualified endpoint estimate.

We investigated whether CRANE's evidence-contract principle can be applied to HEXAR, an independently developed modular robot explainer evaluated on released physical TIAGo executions (Gebelli et al., arXiv:2601.03070). We pinned the released implementation and audited its complete navigation category: six declared situations, 18 recordings and 54 queries. Recalculating the original majority annotations recovered HEXAR accuracy of 167/180 overall and 49/54 on navigation. Those labels measure the authors' original task and do not label our reduced evidence packets.

| Released method | Overall accuracy | Navigation accuracy |
|---|---:|---:|
| HEXAR | 167/180 (92.8%) | 49/54 (90.7%) |
| No reasoning module | 121/180 (67.2%) | 31/54 (57.4%) |
| LLM baseline | 118/180 (65.6%) | 49/54 (90.7%) |

For a first development recording, we verified serialized-input, state, task-window and navigation-prompt parity through isolated ROS Humble replay at the recorded rate, with a shared traced receipt clock. We then applied removal-only interventions before callback/state derivation: intact evidence, irrelevant recorder-log removal, and removal of every retained manual-state representation. The latter preserves reported navigation failure and timeout evidence while making the manual indicator unknown. The release contains logs and state estimates, but no raw scan/path/costmap measurement in this subset. A reported controller progress failure or map-clearing request therefore does not uniquely establish a physical obstacle cause. Even the intact manual indicator supports a bounded mode observation rather than independently proving the controller's inhibition mechanism.

We generated nine outputs per method on these fixed packets: the original navigation prompt, a strengthened calibration prompt, and the same strengthened evidence interface with CRANE's pinned contract planner and constrained realizer. The two new conditions share primitive facts, availability information and a concise output allowance. The contract condition deterministically replaces navigation realization; it is not a post-hoc verifier of arbitrary model prose. All 27 development outputs were retained. The prompt-only control already preserves useful facts and uncertainty in inspected examples, while the contract implementation trades supplemental detail and wording flexibility for concise checked propositions. These observations do not establish a superiority effect.

The prospective external extension of the current agent annotation task failed its coverage-field qualification gate in both isolated passes despite correct atomic-support labels on all eight held-out atoms per pass. We retained that failure without quality retries or retrospective rescoring. Consequently, no new response-level calibration endpoint, paired effect or significance claim is reported. Only one physical recording has been executed semantically in this tranche; repeated questions, masks and model calls are not independent robot executions. A later evaluation must qualify the complete measurement task, validate all six families' masks/references and coordinate any confirmatory allocation with the main study's existing inferential ledger. Public-data familiarity and unresolved historical phi4 artifact identity further limit interpretation.

Permissible intended contribution after successful evaluation: “The same evidence-calibration principle used in CRANE can be added to an independently developed modular explainer and evaluated on released physical robot executions.” Current evidence supports the bounded component integration and executed stress-test feasibility. It does not establish improved explanation calibration beyond a strong prompt control, full HEXAR reproduction, universal root-cause discovery, human trust or new hardware experimentation.
