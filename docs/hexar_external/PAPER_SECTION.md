# External validation — interim, held-out evaluation pending

No statistically supported improvement is currently established. This text supersedes the earlier single-recording draft and will be replaced by the completed reserved evaluation.

We applied CRANE's pinned evidence-contract core to HEXAR, an independently developed modular explainer for released physical TIAGo executions (Love et al., arXiv:2601.03070). The complete released navigation category contains six situation families and 18 recordings. We reproduced the authors' original majority-label calculation: HEXAR scored 167/180 overall and 49/54 navigation queries. Those historical human labels measure a different task and are not used to score our reduced packets.

Our component-level adaptation preserves upstream callback, state, task-window and navigation-prompt logic. An isolated ROS Humble replay at recorded speed verified all 3,422 selected inputs, state updates, windows and prompts under traced receipt-clock instrumentation on one development recording. Bags contain logs, task state and some indicator/localization messages, but no raw scans, paths or costmaps. We apply one universal removal-only transformation before state derivation, preserving execution outcomes while withholding diagnostic channels; an irrelevant-removal control preserves the entire method packet. Clean state and explicit unknown values prevent retained-cause and missing-as-false leakage. Packet-only references preserve temporal and source scope; scenario labels and original answers never enter methods.

We split by recording before comparative tuning: six repetition-1 recordings for development and twelve repetition-2/3 recordings reserved across the same six families. Three conditions compare the unchanged upstream prompt, a strengthened calibration prompt, and the same evidence interface with CRANE contracts. The primary contrast is contract versus strengthened prompt, with equal evidence, public source semantics and a three-sentence/60-word allowance. Model-backed conditions request the same hosted gpt-6-sol/high configuration; historical phi4 artifact identity and hosted weight immutability are unavailable. The contract condition deterministically replaces component realization through the pinned core, using no model call; it is not a post-hoc verifier of unrestricted prose.

The registered primary endpoint is each recording's mean useful-supported-answer success over three original questions and three evidence levels. Success requires a correct useful outcome and one available bounded diagnostic, appropriate unknown scope, and no material unsupported assertion. Valid supplemental detail is allowed; blanket refusal fails. New labels are agent-assessed, with independent packet references, deterministic numerical checks, a method-blind developer proposition inventory and qualified isolated support passes. Developer extraction is not qualified or human-validated.

The full-query development pilot generated 162 valid responses but retained 24 judge-protocol failures (85.2% technical completion), below the unchanged 90% admission gate. Its full-cohort contract-minus-prompt effect bounds were [−3.7, +22.2] percentage points. The strengthened prompt already preserved all required units and made no unsupported physical-cause assertions among finalized labels. A broader unsupported-detail gap therefore cannot be described as reduced physical-cause guessing. Contract realization trades supplemental detail and lexical flexibility for concise checked statements. We retained the failed measurement version without retries or rescoring, independently qualified a sentinel-only compatibility clarification on fresh synthetic fixtures, and regenerated a prospectively fixed all-family q1 infrastructure slice. That slice adds no physical N and does not replace the held-out endpoint.

The held-out evaluation remains gated on qualified technical completion and a hash-bound descriptive freeze. No external alpha is allocated or consumed, and no superiority p-value is permitted. Twelve physical recordings and six shared families, public-data familiarity, limited causal evidence, agent/atomizer uncertainty, component-only parity and unequal model use restrict interpretation. The intended contribution is a bounded application of the same evidence-calibration principle to an independent explainer on released robot executions, conditional on the completed comparison; no overall HEXAR replacement, human-trust or unseen-mechanism claim follows.
