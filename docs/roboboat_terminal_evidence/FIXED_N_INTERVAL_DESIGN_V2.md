# Fixed-N interval candidate v2 — additive engineering repair

This additive SIMULATED-only module preserves the reviewed v1 source/tests/document and independent-review artifact. No study observations, final method/N/bet selection, confirmation freeze or inference activation are involved.

The repaired API accepts separate ordered geometry-score arrays `adverse_scores` and `favorable_scores`. It requires finite values in [-1,1], the same nonzero N and pointwise adverse≤favorable, then reports `[L(adverse), U(favorable)]`. Geometry identity/order matching is a caller responsibility; matching lengths alone does not establish identity. Complete data use the same array twice. Applying both tails to adverse scores is explicitly avoided: twenty latent +1 scores with fully missing judgments have adverse -1 and favorable +1, yielding [-1,1]; an interval on adverse alone would falsely give a negative upper bound.

For independent latent complete scores D_i and pointwise bounds A_i≤D_i≤F_i, the positive-lambda e-statistic is increasing in each score. Consequently L(A)≤L(D), while U(F)≥U(D). The observed-bound interval contains the complete-data interval realization by realization, regardless of whether missingness depends on outcomes. Complete-data lower and upper tail noncoverage probabilities are each at most alpha under the fixed-allocation average-expectation estimand; union bound gives at least 1−2alpha simultaneous coverage. This does not require independence between tails or a missing-at-random assumption. It retains independence of the latent geometry scores and estimand-compatible fixed allocations. Bounds on the observed realized scores do not make an arbitrary stopped or differently weighted population estimand valid.

The existing centering and AM–GM argument remains intact. For candidate m>-1, factors are `1−lambda+lambda*(D_i+1)/(1+m)` and strictly positive. Independence and AM–GM bound expected product by one under average E[D_i]≤m. Centered values may exceed +1 for negative m, which does not invalidate this positivity/expectation proof. The factor and each fixed positive-weight mixture decrease with m. A single fixed-N inversion supplies the lower confidence bound; negation supplies the upper bound. No anytime validity under the heterogeneous weak average null is claimed.

V2 evaluates the statistic with 80-digit Decimal arithmetic, exactly converting declared binary float score/lambda/alpha inputs, renormalizing the fixed weights in Decimal, aggregating repeated scores by multiplicity and using log-sum-exp. It uses 180 bisection steps, lower endpoint −1+10⁻³⁰ and upper endpoint 1. If the lower-endpoint test does not reject, the support endpoint −1 is returned, conservatively covering any root still closer to −1. Otherwise it subtracts a fixed **10⁻¹² numerical margin** from the lower bisection bracket, rounds the final float toward minus infinity using `nextafter`, and clips at −1. Negated upper-tail evaluation widens the other side correspondingly. A zero/constant endpoint case remains within known support.

This is a conservatively declared engineering safeguard, **not certified interval arithmetic**. Decimal elementary operations are finite precision, and the margin is not a derived universal error bound over arbitrary N, nearly singular m or extreme lambda/weight settings. We do not claim rigorous outward rounding of the exact mathematical root solely from the implementation. The repaired numerical margin dominates the approximately 10⁻¹⁶ overshoots found in the independent v1 audit and is checked against separate 110-digit analytic constant-score roots. A strict numerical certification for a final analysis release would require bounded input/parameter/N ranges plus a verified error envelope or genuinely directed interval evaluation. No such release is selected here. The margin introduces negligible extra conservatism in planning units but must be frozen/documented with the eventual implementation.

Tests include exact enumeration of all 64 draws from an independent heterogeneous six-score Bernoulli population with negative average expectation and outcome-dependent missingness. They retain every draw in probability accounting, verify missing intervals contain complete intervals pointwise, and verify coverage/noncoverage against the analytic bound. Further tests cover the adverse-only counterexample, informative bound expansion, complete-array/support endpoints, high-precision root direction, mismatched/reversed/out-of-range bounds, invalid settings and non-SIMULATED origins. These are implementation checks, not measured study reliability or a selected primary confidence procedure.
