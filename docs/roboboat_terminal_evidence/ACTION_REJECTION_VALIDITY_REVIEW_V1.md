# Action rejection: benchmark quality versus study validity — development review

This is a design review candidate, not a revised active validity rule. Existing captures, strict collector definitions, failed dispositions and confirmationN0 remain unchanged. No method outcomes were inspected to motivate this review. User authorizes development refinement and requires scientific validity rather than an arbitrary recording ceiling.

The inherited CraneBenchmarkRunner worker.valid combines errors, observation failures/staleness, any stale action, cross-episode action, depth-buffer mismatch and water-search invalidity. summarize_nav2_reset also requires zero rejected/stale actions and a selected expected navigation status. Collectorv7 already separates expected navigation status from observation validity but still inherits worker.valid and zero rejected/stale gates. Exact gate source rejects before actuator mutation when applicationTick minus sourceObservationTick exceeds its declared10-tick bound. Therefore one correctly rejected late command is a real execution event, not by itself proof of a corrupted recording or incorrectly applied action. Current fresh .04-clock attempts have1/4 such rejections and zero sensor overflow. Accepted-only summaries cannot certify which receipts were rejected or whether every other validity field is sound.

The original performance benchmark asks for a clean latency workload. The explanation study asks whether both methods explain faithfully recorded robot-visible navigation/docking evidence. A scientifically valid future episode may contain correctly recorded controller/transport faults, rejected commands or unrecoverable navigation, provided the physics, episode identity, observations and receipt decisions are traceable. Keeping an outcome-dependent performance gate can unnecessarily narrow the population to unusually clean runs. Conversely, merely allowing stale counts without complete accounting would hide unknown acquisition/clock/transport defects and is not justified.

Review prospective trace-qualified admission after isolated instrumentation is tested. Required evidence before any candidate activation: exact received/overwritten/consumed/pending/cleared conservation; gate accepted/rejected accounting matches worker counters; no audit drops/writer errors; every rejected receipt has source/receive/application times and a permissible rejection reason; every accepted action remains within the actual gate policy; no cross-episode application; unchanged command payload/QoS/controller/physics/sensing; valid complete immutable robot-visible evidence exports and independently checked clock mapping. Retain strict observation, runtime-error, depth-buffer, water, endpoint identity and namespace gates. Correct stale rejection would become recorded execution behavior, with its incidence/rate and sensitivity reported, rather than silent failure deletion. This requires a new instrumented source/platform/collector/evidence version and fresh predeclared rows. Existing failed rows are never silently reclaimed as valid scientificN.

Do not select arbitrary tolerable rejected-action rates from favorable answers. If command timing needs improvement, diagnose and repair it independently of explanation scores. A future inclusion rule should state whether correctly enforced rejection is admissible behavior and what trace completeness means; a latency-quality sensitivity can additionally retain zero-rejection episodes. Neither rule changes the inference sampling unit or pools land evidence. Source-clock mismatches, genuinely accepted stale commands or incomplete traces remain blockers. Correct rejection may supply useful robot-visible evidence if exposed identically to both methods, but cannot establish Nav2 internal sample consumption, transport residence or a physical cause without the corresponding measurements.

No validity change or gate weakening is active. Independent scientific/engineering review of this distinction remains pending; mature confirmation must freeze whichever defensible rule is selected before its governed recordings.
