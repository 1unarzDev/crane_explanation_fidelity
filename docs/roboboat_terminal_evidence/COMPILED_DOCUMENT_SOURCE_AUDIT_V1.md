# Compiled Unity source checksum audit — development

The additive portable-PDB audit checks the actual bound v6 managed assemblies and their debug documents. All 34 common robot-source candidates in the prepared baseline interface match their compiled document checksums under matched assembly/PDB metadata. This closes the earlier source-list omission for these candidates: the scene asset manifest covered only six, whereas portable debug documents cover all 34. It does not establish scene wiring, runtime initialization, component execution, reflective dependencies or source-to-behavior equivalence.

The audit verifies the exhaustive 372-file build manifest before and after reading metadata. For each managed PDB, the utility records the PE CodeView GUID, stamp and age, portable PDB content ID, and PE checksum when supplied. Portable-PDB checksum verification zeroes the 20-byte content ID at the metadata-reported offset before hashing; raw artifact SHA256 is retained separately. Source documents are compared only under the explicit project root, without suffix guessing or external-path reads. Unknown algorithms, unavailable documents, invalid metadata and checksum mismatches stay explicit. No source or build bytes changed.

The actual run contains 50 matched metadata pairs, 79 unqualified pairs and one unreadable PDB. All public-source candidates occur under matched metadata. Among project-root documents there are 3,434 source checksum matches and four unavailable generated sources. These four are inference-model generator outputs; complete compiled source closure is therefore not claimed. Package/editor/generated documents are recorded alongside robot documents, rather than filtered away. Repeated documents are not distinct scientific observations.

Artifacts are `artifacts/roboboat-compiled-document-source-audit-v1/audit.json` and `receipt.json`. The receipt binds the utility sources, compiled utility/runtime files, Python audit sources, tests, original build manifest and output. Three tests pass using freshly compiled real assemblies: correct ID/checksum/document matching, mismatched and malformed PDB rejection, and changed/missing/outside-root source handling. SDK version is 10.0.401. Runtime deployment authentication and independent review remain pending. Baseline call readiness stays false; no explanation calls, scores or scientific N are added.
