# Reuse audit and additive decisions

Legacy code and frozen artifacts are untouched. `export_terminal_margin_diagnostic.py` is explicitly success-only; it cannot define a general docking population. Its regex takes the first YAML key, not the active controller node/plugin. Its return time is the first `phase=post_result` sample, whereas its return pose/motion is the last earlier observation. `recompute_terminal_margin_diagnostic.py` reuses production diagnosis and is not independent validation. `reference_terminal_margin.py` has a separate arithmetic path but shares the unscoped YAML extraction and only endpoint-level support.

Legacy exports contain diagnostic_result, checked_answer, and final_text_verification. The method-input adapter strips those top-level outputs. The endpoint mask is not genuine information removal: final_pose survives settled_error removal; action_result_pose permits return-error derivation; retained trajectory/source paths could reconstruct motion. Speed-only removal does not establish impossibility of finite-difference average-motion estimation when pose history remains.

The new marine adapter starts from fixture primitive observations with allowlists and builds L0–L2 by removal. No summary endpoint, evaluator label, source-record path/hash, or answer appears in a method packet. Exact public task/config identity is retained. The batch's evaluator provenance is physically separate. A source/tool workspace must omit full recordings and evaluator material; merely asking an agent not to inspect paths is insufficient. Do not promote a baseline comparison if isolation has not been tested.

New capture adds terminalEventV2: actual client result-receipt monotonic timestamp, action goal UUID/status, latest-delivered odometry snapshot/stamp and measurement source. Receipt time is not claimed to be server result-production time or simulator time. Per-sample odom and child frames are captured. Historical replay keeps unknown event identity/time and labels the last pre-result observation honestly. No fabricated event timestamp is introduced.

The fixed observation-aligned five-second dwell avoids mapping a reception clock to a simulation clock without a measured bridge. This is a separately declared sampled contract, not a revision of legacy continuous docking requirements. Continuous completion stays unknown without intersample bounds. A supported point violation in the declared interval establishes failure. Missing contact telemetry cannot become “no contact”; no evaluator contact truth enters a method packet. L3 is deferred.

World-frame velocity is the rotation of measured body surge/sway, never action-feedback command speed. Radial error is computed from the recorded pose. Net endpoint displacement, arclength, and radial-error growth remain distinct. Crossing brackets name the last compliant and first violating **observations**, not exact continuous crossing times. Independent reference uses a different wrapped-angle expression and footprint extents, not the production corner calculation.

The parent/main YAML and live docking YAML both differ from the committed validated marine configuration. Read config from crane_ml `60439faa5df320e54082ad0dfedad635442adf07`, not a working file. Versioned experiment YAML and runtime checker override leave defaults unchanged. Historical config uses its original committed `4ae5124c...` bytes. Effective pilot configuration retains the launch override separately from its base hash; its resolved method config contains the effective threshold.
