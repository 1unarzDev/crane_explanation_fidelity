# Fixed-test power sensitivity: development only

The prospective test remains unselected. This report compares the existing equal-weight eleven-bet mixture with seven alternative single-bet tests. Each alternative would require its own bet and N fixed using development information before confirmation; choosing the maximum statistic after seeing confirmation is not allowed. No real recording, answer, annotation or pilot effect is read. The user-selected complete supported diagnostic-answer endpoint is unchanged; the provisional geometry score remains the mean of six paired answer-success differences.

For a single fixed lambda in(0,1), independence and AM-GM give E[product(1+lambda*X_i)]≤1 under the weak nonpositive average-expectation null, even with heterogeneous independent geometry distributions. Markov bounds type-I error at the chosen alpha. This is the same fixed-N argument as the previously reviewed mixture/interval candidate. It is not an optional-stopping argument. The exact-rational interval implementation supports single-bet settings, but a final analysis still needs its own prospective specification and independent review. Floating simulation thresholds are planning calculations, not empirical inferential release.

Wilson intervals express Monte Carlo uncertainty only and are not simultaneous guarantees or uncertainty about real effects. All null-stress aggregate means were checked nonpositive; the largest simulated null rejection probability was.0042 at nominal alpha.025.
