# Exact fixed-N inversion candidate for the six-question geometry endpoint

Development engineering only. No real answers/labels, final hypothesis/test/N, empirical inferential release, endpoint change or confirmation freeze. User-selected complete supported diagnostic answers remains the endpoint; provisional geometry mean is two variants times three evidence levels. This candidate accepts exact integer numerators from -6 through6, representing D_i=numerator_i/6. It refuses floats, arbitrary off-lattice scores, empirical origins and N above5000. Caller must preserve geometry identity/order and independent latent scores; input length is not an independence proof.

The fixed-N mixture argument is unchanged: positive bets belowone and normalized positive rational weights yield factors1-lambda+lambda*(D_i+1)/(1+m). Independence and AM-GM bound the expected mixture byone under the heterogeneous fixed-allocation average-expectation null. It is not an anytime-valid monitor for that weak null. Alpha per tail must be specified prospectively; the default1/40 is an engineering example, not selected final inference.

Unlike Decimal inversion with an empirical numerical margin, every candidate m, factor, exponent, mixture weight and threshold comparison uses exact fractions backed by Python arbitrary-precision integers. Scores have thirteen possible values and aggregate by exact multiplicity. With any D_i>-1, the statistic diverges as m approaches-1 and is below1/alpha at m=1; monotonicity brackets its root. If all scores are-1, the support lower endpoint is exact. Forty-eight exact bisections produce a rational bracket of width at most2/2^48. The lower bracket is the conservative lower confidence endpoint. The negated lower bracket on favorable scores supplies the conservative upper endpoint. Outward conversion compares the binaryfloat exactly with the Fraction and uses nextafter only when necessary. No assumed Decimal-error envelope is needed for this inversion.

Pointwise adverse/favorable score bounds retain outcome-dependent missingness without assuming missing at random: report[L(adverse),U(favorable)]. Monotonicity ensures containment of the complete-score interval realization by realization. The confidence-coverage argument still depends on the prospective sampling/estimand and fixed-N assumptions; exact arithmetic cannot repair dependence, optional stopping, selective scenario filtering or an invalid method comparison.

These are implementation tests, not measured annotation reliability.
