# Synthetic terminal-analysis runtime probe

Declared before execution. This is development engineering only and reads no episodes, labels or study outputs. It does not select N, change the test or consume alpha. The unmodified adopted candidate mixture's exact decision and 48-step directed-arithmetic interval inversion are exercised together on four predetermined hypothetical count sets: (favorable, unfavorable, N) = (40,32,72), (63,51,114), (390,260,1296), (1690,1382,3072). These represent modest positive effects, including substantial reverse discordance and tied episodes in the third case. They are not predicted or acquired outcomes.

Use isolated sequential worker processes with a 60-second limit per case. Archive the complete declaration and candidate sources before workers start; preserve each original stdout, stderr, return code, timing and disposition. A timeout remains an engineering failure rather than permission to drop the confidence interval, approximate the significance decision or change the confirmatory test. No retry is needed to report a timed-out probe. All four cases must complete with finite ordered bounds and exact-direction agreement for the runtime screen to pass. Completion on synthetic examples does not qualify the complete terminal adapter, full dependency closure or statistical assumptions.
