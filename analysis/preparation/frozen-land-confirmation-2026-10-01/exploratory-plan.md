# Post-release descriptive analysis plan

Prepared before registered confirmation release; this plan does not change the frozen primary analysis or add alpha. Confirmation outcomes remain inaccessible during preparation. Development results are explicitly separate.

After terminal release, report numerical/interval errors from the frozen annotation fields, useful required-unit coverage using the frozen A/B intersection and equal episode weighting, and evidence-level PrimaryFailure/unsupported-specificity behavior. Show both annotation-pass estimates as sensitivity analyses. Do not treat levels, units, calls or judge passes as independent episodes. Use episode-level resampling for any exploratory interval and label these intervals descriptive; retain the frozen exact interval for the primary result.

Numerical accuracy: report counts and episode proportions with at least one factual numeric/interval error, by method and evidence level. Denominators include all scored episodes; also report the number with numeric claims if available from retained fields without adding a new judge. Do not infer perfect numerical accuracy from the absence of a numeric claim.

Useful coverage: report mean episode fraction for each method, paired coverage difference, and per-unit/level inventory and communication counts. The predeclared B4 >=95% floor and <=5 percentage point loss remain the scientific success requirement. Additional coverage summaries do not rescue failure of either threshold.

Evidence ladder: report each level separately and within-episode changes as descriptive repeated measures. Preserve distinctions among recovery-action occurrence, measured recovery, observation and hidden physical cause. Do not select a level as a replacement primary endpoint.

Resources: report technical metadata on elapsed capture/generation/annotation time, calls, timeout/provider failures and tokens/cost only where actually retained. Distinguish wall time from worker-time and provider usage from estimated price. Do not issue new model calls for this analysis.

Strata: report profile, geometry and realized persistent/recovery counts and descriptive paired estimates after release. The frozen sampling population and equal-weight primary remain unchanged; controls and other baselines are secondary only when retained outputs exist.

Missingness: preserve the complete-pair primary and frozen arbitrary missing-pair sensitivity bounds. Report all physical exclusions, capture failures and incomplete method pairs separately. No unfavorable valid episode is replaced. Automated annotation agreement is not human validation, and null results do not establish equivalence.
